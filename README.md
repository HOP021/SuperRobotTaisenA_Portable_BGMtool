# ほっぷtool SRW A P（スーパーロボット大戦A ポータブル BGM 差し替えツール）

日本語 | [English](README_en.md)

スーパーロボット大戦A ポータブル の BGM を、手持ちの音源に差し替える Android アプリです。
PPSSPP などで遊ぶための ISO / CSO を、スマホだけで書き換えられます。

- ダウンロード: [SRWAP_BGMtool.apk](SRWAP_BGMtool.apk)
- **MX ポータブル版**: [SRWMXP_BGMtool.apk](SRWMXP_BGMtool.apk)（ほっぷtool SRW MX P。使い方は A 版と同じです → [MX ポータブル版について](#mx-ポータブル版について)）
- **α3（PS2）版**: [SRWA3_BGMtool.apk](SRWA3_BGMtool.apk)（ほっぷtool SRW α3 → [α3 版について](#α3-版について)）
- **Windows 版**: [HopTool_Windows.zip](HopTool_Windows.zip)（A P・MX P・α3 を 1 つにまとめたもの → [Windows 版について](#windows-版について)）
- 対応: Android 7.0 以上（arm64-v8a / armeabi-v7a / x86_64）
- 端末・PC の言語が日本語以外のときは、英語で表示されます

> **ゲームのデータは含みません。** 自分で持っているソフトから吸い出した ISO / CSO に対して、
> 個人で楽しむ範囲で使ってください。

## できること

- **BGM の差し替え**: mp3 / flac / wav / m4a、mp4 などの動画（音声だけ取り出し）から曲を読み込み、ゲームの形式（ATRAC3）に変換して書き込みます
- **編集画面**（InShot 風）: 複数の音源を並べてつなげる・重ねる、分割、長さ調整、音源ごとの音量とフェード、元に戻す
- **ループ位置**: 波形の上の L / R の旗で指定。「つなぎ目を自然に」で、ループで先頭に戻る瞬間をなめらかに
- **元の曲を聴く**: ISO / CSO に入っている曲を、ゲームと同じループで試聴。元の曲を音源として編集に使うことも可能
- **曲名の変更**: 曲をタップ →「曲名を変える」
- **音量をそろえる**: 差し替える曲ごとに元の曲の音量を測って合わせます（さらに大きくすることも可能）
- **CSO 対応**: CSO は元のファイルを残したまま、新しい CSO を作ります
- **BPS パッチの作成**: 元と書き換え後（ISO / CSO どちらでも）から、ISO に当てられる BPS パッチを作ります
- 起動時のロゴ画面は、書き込むときに「ほっぷmod」のロゴに差し替わります

## インストール

1. [SRWAP_BGMtool.apk](SRWAP_BGMtool.apk) をスマホにダウンロード
2. 開いてインストール（「提供元不明のアプリ」の許可を求められたら許可）

## 使い方

1. **ISO / CSO を選ぶ**
   - ISO はそのファイルを直接書き換えます。**必ずコピーを選んでください**
   - CSO は元のファイルはそのままで、新しい CSO を作ります
2. 曲の一覧から差し替えたい曲をタップ →「曲を選んで差し替える」
3. 編集画面で長さやループを整えて「決定」
   - 赤い線より長い曲は入りません（元の曲の場所に、元の曲と同じ音質で書き込むため）
4. 「書き込む」→ 音量の設定を選んで実行
5. PPSSPP で起動して確認

### 番号について

- 01〜45: ゲームのサウンドテストと同じ番号・同じ曲
- 26: タイトル画面の曲（「極めて近く、限りなく遠い世界に」と同じデータ）
- 00: 26 番と同じ中身の控え（タイトル画面では使われません）
- 25: 使われていない仮置き

### 曲名の初期設定

アプリには作者が使っている曲名の変更が最初から入っています。
不要なら「曲名の変更をすべて取り消す」を押してから書き込んでください。

## MX ポータブル版について

スーパーロボット大戦MX ポータブル 用の別アプリです。A 版と同時にインストールできます。

- ダウンロード: [SRWMXP_BGMtool.apk](SRWMXP_BGMtool.apk)
- 画面と操作は A 版と同じです
- 81: タイトル画面の曲
- 85: 「魂のルフラン」の別バージョン

## α3 版について

スーパーロボット大戦α3（PS2、SLPS_255.37）用の別アプリです。A 版・MX 版と同時にインストールできます。
NetherSX2 などの PS2 エミュレーターで遊ぶための ISO を書き換えます。

- ダウンロード: [SRWA3_BGMtool.apk](SRWA3_BGMtool.apk)
- 対応するのは ISO だけです（ISO を直接書き換えるので、**必ずコピーを選んでください**）
- 曲の選び方・編集画面は A 版と同じです
- 差し替えた曲は、ディスクから少しずつ読みながら鳴らします
- **書き込み済みの曲を編集する**: 書き込んだ曲を読み出して、編集画面で直せます
- **元の曲に戻す / 全部元に戻す**: 差し替えた曲を元に戻せます。全部戻すと、元のままの ISO になります
- **元の曲を聴く**: ゲーム機の音源をまねて鳴らします（実際のゲームとは少し響きが違います）
- **音質**: 標準（32kHz）と途切れにくい（24kHz・高音が少しこもる）から選べます。ふだんは標準で大丈夫です
- 曲を選ばずに「ISO に書き込む」を押すと、書き込み済みの曲はそのままで、再生のしくみと起動ロゴだけを最新にします。アプリを新しくしたら、一度これをしてください
- ISO が 1 層 DVD の大きさ（4.38 GB）を超えると、エミュレーターで曲が読めないことがあります。そのときはもう一度「ISO に書き込む」を押すと、使っていない古い曲の分を詰めて小さくします

## Windows 版について

A P・MX P・α3 の 3 つを 1 つにまとめた Windows 用のアプリです。ISO / CSO を開くと、どのゲームかを自動で判別します。

- ダウンロード: [HopTool_Windows.zip](HopTool_Windows.zip)
- 対応: Windows 10 / 11（64 ビット）
- インストールは不要です。zip を**全部展開**して、展開したフォルダの `HopTool.exe` をダブルクリックしてください（Java も中に入っています）
- 画面と操作は Android 版と同じです。編集画面はマウスで操作します（何もない所をドラッグ: 曲が流れる、Ctrl + ホイール: 拡大縮小、スペース: 再生 / 停止）
- 起動時のロゴは、書き込むたびに「ほっぷmod」のロゴに差し替わります

## 注意

- 差し替えた曲を含むパッチや ISO / CSO を配布しないでください。中身の大部分が曲そのもので、作詞・作曲者やレコード会社の権利に触れます
- A 版・MX 版は、ゲームが曲を丸ごとメモリに読み込むため、長さには上限があります（編集画面の赤い線）
- 書き換える前に、元の ISO / CSO を必ず残しておいてください
- α3 版で書き込んだあとは、ステートセーブからではなく、ゲームを起動し直して遊んでください（書き込む前のステートセーブでは、音が鳴らないことがあります）
